# Цифровая фотография

Анонимное учебное фотопортфолио: Vite, JavaScript, Three.js. Статический сайт без бэкенда. Шрифты и иконки поставляются локально, внешние API не нужны.

## Запуск

Node.js 22.12+ или 24 LTS.

```sh
npm ci
npm run dev
```

```sh
npm run build
npm run preview
```

## Фотографии и подписи

**Оригинальные вложения пока недоступны как файлы в среде.** Текущая версия использует временные фрагменты одобренного сгенерированного макета (`public/images/approved-reference.png`), а не оригинальные снимки. Они подходят для проверки композиции, но не для финальной презентации. Нельзя выдавать их за исходные фотографии.

После получения оригиналов:

1. Поместить изображения в `public/photos/`.
2. В `src/works.js` заменить `src: null` на `/photos/имя-файла.jpg`.
3. При необходимости обновить `title`, `description`, `alt` и пропорции `crop` (используются как соотношение сторон; для оригинала координаты не применяются).

Там же добавляются последующие работы. Сортировка и переключение в просмотрщике следуют порядку массива. Предусмотрены клавиши ←/→, Escape, возврат фокуса, мобильная версия, reduced-motion и кнопка паузы. WebGL-эффект отключает обновление вне экрана, при открытом просмотрщике и в скрытой вкладке.

## Vercel

Импортировать репозиторий в Vercel. Framework Preset: **Vite**, Build Command: `npm run build`, Output Directory: `dist`. Секреты и сервер не нужны. Публикация из этой среды не выполнялась.

## Проверки

Сборка `npm run build` прошла. В Chromium проверены версии 1440px и 390px, открытие/листание/закрытие фотографий, описание проекта, reduced-motion и отсутствие горизонтальной прокрутки. Ошибок JavaScript не было. Скриншоты находятся в `.impeccable/review/` (локальные, не в Git).

Остаётся заменить временные изображения оригиналами; статус визуальной проверки записан в `design-qa.md`.
